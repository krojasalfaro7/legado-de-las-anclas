# CLAUDE.md — Legado de las Anclas

Original top-down action-RPG (Phaser 4 + TypeScript strict + Vite). Personal, non-commercial.
(The folder is still `dbs-legacy/` from the project's first name.)

## Commands

- `npm run dev` — dev server (http://localhost:5173). Params: `?debug=1`, `?zone=<id>&spawn=<id>`.
- `npm run lint` / `npm run format` — Biome (lint + format, single tool).
- `npm run test` — Vitest (pure logic only, `tests/`).
- `npm run build` — `tsc` typecheck + Vite build to `dist/`.
- `npm run assets` — regenerate placeholder tileset PNG and Tiled maps from `scripts/`.
- `npm run sprites:check` / `npm run sprites:templates` — validate hand-drawn sheets (writes
  `public/assets/sprites/manifest.json`) / write drawing templates to `docs/sprite-templates/`.

## Conventions

- Code, file names and comments in English; all player-facing text in Spanish in `src/i18n/es.ts`.
- Comments only to explain _why_. Small functions, explicit types at module boundaries.
- Pure game logic lives in `src/systems/` and must not import Phaser (so Vitest can run it in node).
- Content is data-driven: `src/data/`. Adding an enemy/item/zone should not require logic changes.
- All content is original: no art, characters, names or story from existing games, anime or manga
  (no ROM extraction either). Art is generated by code (`src/ui/textures.ts`,
  `scripts/gen-tileset.ts`) or loaded from original files.
- Each phase ends with lint + test + build green and a commit.

## Decisions log (choices not covered by the original brief)

- Phaser **4.2.1** (latest stable on npm at project start).
- Resolution: the user asked for a closer camera (~16 tiles tall), then for a full-screen
  picture, then (comparing with GBA footage, where a 30 px fighter fills a 160 px screen) closer
  still: ~13 tiles. `config/constants.ts` derives the internal size from the **monitor** at boot:
  whole zoom `floor(screenH / 200)`, size `screen / zoom` (1920×1080 → 384×216 at 5x, 1366×768 →
  456×256 at 3x). UI must fit 384×216: pause panel has thin margins, the Lens title sits top-right;
  width capped at 480 (hub map width). Fullscreen (key F, toggled from the DOM keydown handler
  because browsers need a user gesture) is therefore pixel-exact with no bars; in a window
  `Scale.FIT` fills the height. The size is fixed for the session so scenes can lay out once.
- Text uses a hand-made pixel bitmap font baked at runtime (`src/ui/pixelFont*.ts`) because
  system fonts are blurry at 480×320. `pxs` has a baked 1px shadow; tint it freely.
- Maps are authored as ASCII in `scripts/maps/` and compiled to real Tiled `.tmj` (Tiled isn't
  installed on the dev machine). The output opens and edits fine in Tiled.
- Collision: a **tile layer named `Collision`**; any tile whose tileset property `collides` is
  `true` blocks movement (`setCollisionByProperty`). The map compiler puts solid tiles there
  automatically and fills the `Ground` layer underneath.
- Browser-bound singletons (input, audio, storage) live in `src/services/`, not `systems/`.
- Input does not use Phaser's input plugins: `services/input.ts` reads DOM keyboard + Gamepad API
  once per game step (`PRE_STEP`) so all scenes share the same edge-detected state. Closing a menu
  calls `input.consumeAll()` so the same key press doesn't leak into the world.
- Dev builds expose `window.__game` for console debugging and smoke tests.
- The field zone is **one 60×40 map with a following camera** (2×2 screens) instead of several
  maps linked by edge transitions: no seam logic, enemies can chase across "screens", and the
  camera bounds do the rest. Edge/door `transition` objects are still supported for future zones.
- NPC behavior is declarative (`systems/npcRules.ts`): ordered rules of condition → dialogue +
  effects. `chain: true` re-evaluates after a dialogue (deliver collectibles, then reward).
- Stable ids for persistence are `<zoneId>:<TiledObjectName>` (chests, gates, bosses, groups),
  so renaming an object in Tiled resets its saved state.
- Enemies respawn every time a zone loads (grinding like the GBA games); bosses don't once beaten.
- Death offers: continue from last save, retry the zone keeping progress, or back to title.
- Party: `GameState.partyOrder` + `activeCharacter` with pure helpers in `systems/party.ts`.
  Each `CharacterProgress` keeps its own `vitals` (save v3); switching doesn't heal, save circles
  and retry restore the whole party (`restoreParty`). Okun joins through `joinFlag: 'okunJoined'`
  (`isPlayable`); R/RT tags the next member in place (`Player.switchTo`, ground only, not mid-
  action or transformed). Dev builds accept `?join=okun` with `?zone=` to test him early.
- Objectives (user request: "what should I do?"): `data/objectives.ts` lists main/side
  objectives whose steps complete on the same conditions as NPC rules (`systems/objectives.ts`
  walks them in order). The pause tab "Misiones" shows done steps and the current one only.
  New story beats should add their steps here.
- Barriers (phase 19): Tiled `gate` objects with `kind` = `level` (default; colored, level shown),
  `boulder` (only `requiredCharacter`'s punches crack it, `BOULDER_HITS`, finisher counts
  double; the attack button punches it instead of interacting) or `seal` (`openFlag` + `hintKey`,
  opens by itself when the flag is set, not stored in `brokenGates`). Rules are pure in
  `systems/barriers.ts`. `tests/content.test.ts` flood-fills every zone (flying rules outdoors)
  and fails if anything is unreachable with all barriers open or if closing any one barrier
  hides nothing — i.e. no barrier can be skipped.
- Combat phase 23 (user: "fight like Buu's Fury"; reference: public GBA FAQ — separate melee and
  energy buttons, a button to switch attacks, block, block+energy combo, double-tap run): holding
  ki charges the blast (`charge` phase; tap < `chargeTapMs` is a plain shot, full at
  `chargeFullMs`: ×2.5 damage, ×2 cost, pierces, trimmed to the ki you have — `chargedShot`);
  guard + ki held is `focus` (stand still, +30 ki/s, a half guard: ×0.5 damage, no ki cost);
  punches and guard work in the air too (ki still only regenerates on its own on the ground).
- Techniques grow with level (`CharacterDef.techniqueUnlocks`, `learnByLevel`, idempotent so
  old saves catch up on zone load): Tavi 6 Ráfaga de Correo (`burst`: a barrage), 12 Disco de
  Marea (piercing disc); Okun 13 Roca Rodante, 16 Puño Sísmico (short shard cone). Story
  rewards (Pim's Rayo Faro) still come through `learnTechnique` effects.
- Fighters differ through `CharacterDef.traits` (ki regen, charge time, run speed, guard leak,
  armored swings, finisher quake): Tavi charges/recovers fast and runs fastest; Okun's swings
  can't be interrupted (hits still hurt), his guard leaks half as much, and his finisher
  cracks the ground (half damage to enemies within 30 px).
- Reference footage pass (user's links to public let's-play videos; only timings and behavior
  measured, nothing copied): signature beams are sustained, not shots — `KiTechniqueDef.beam`
  gathers a ball in the hands, then holds on the first enemy in line (ticks of `power`, pushes it
  straight back along the beam, keeps it stunned), runs to the screen edge when nothing is in the
  way, and when it ends the cut-off tail flies away. Beams don't charge: pressing fires at once
  and the beam lasts while the button is held (`kiPerSec`, `minHoldMs`/`maxHoldMs`), growing out
  of the hands. The caster is rooted; getting hurt cuts it. Pure geometry in `systems/beam.ts`,
  drawing and ticks in `entities/Beam.ts`. Tavi's Rayo Faro and Okun's Veta de Magma (level 14)
  are beams. Struck enemies flash solid red. Boss pattern `blink` (Sarn's crystal form): shatters,
  vanishes 260 ms, re-forms behind the player (or beside/in front if a wall is there) with a quick
  swing. Combo pace slowed to ~280 ms per punch (footage: ~1/3 s).
- Hit feel (footage at 60 fps, measured per frame): hit-stop `hitStopMs` 60 / finisher 100 (≈4–6
  frames, physics and anims freeze); the struck sprite jitters meanwhile, fills red ~4 frames and
  drains through pink (`flashTint`); a white impact flash pops on the side the blow came from;
  every swing draws speed streaks ahead of the fist (`swingTrail`). Plain hits push ~3 px; the
  finisher launches ~45 px (360 knockback, slide 1.5x longer, `enemyLaunchStunMs`). Knockback
  slides start after the hit-stop (`knock.until` includes it). Defeated enemies vanish in a dust
  puff.
- Special-attack impacts: every ki hit pops a shockwave ring, core glow and sparks in the
  technique's color (`kiImpact`) and pushes the target along the blast's flight. `heavy`
  techniques (Disco de Marea, Lanza de Roca, Roca Rodante, Puño Sísmico) and fully charged
  blasts launch like a finisher: heavy hit-stop, ~45 px slide, the target tossed up in an arc
  that lands in dust. Beams end with a launching blow (2x damage, 3.5x push) on whoever they
  pin. The player gets the same red flash and a short hit-stop when hurt.
- Enemy variety (`EnemyDef.traits`, pure rules in `systems/enemyTraits.ts`): `guard` blocks
  frontal hits while not attacking (15% chip, min 1, no stagger) until a combo finisher or a
  charged/piercing blast breaks it for 1.6 s — or hit it from behind; `dodgeChance` rolls once
  per player blast that comes within 60 px, sidestepping across its path (1.1 s cooldown);
  `absorbKi` turns blasts into healing (half the damage), so only punches work. The first time
  each trait shows up in a zone a toast explains it; Lens descriptions say it too. Placed:
  Escudero gris (field camp/south), Corredora de bruma (field east/NE), Sanguijuela de cristal
  (cobre south/pocket).
- Boss duels (second reference video, a 1v1 boss fight measured at 8 fps): bosses open by
  keeping their distance and throwing (`BossPhase.keepAway`: Grell 80, Sarn 85) and close in once
  hurt; up close they circle to the flank (`closeIn`, orbit flips every 1.2-2.6 s) instead of
  walking straight in; melee comes in strings (`AiParams.meleeChain`: Grell 2, Okun 3, Sarn 3)
  with a 220 ms re-windup (~370 ms blow to blow), follow-ups at 75% damage, a white slash on every
  enemy blow, and half the time a sidestep afterwards. Player i-frames went 700 -> 320 ms so each
  blow of a string lands, as in the footage.
- `flying` trait (Planeador gris, field east4 and cobre trail2): hovers 12 px up and punches pass
  under it (`outOfReach`: no damage, no hit-stop). Any ki hit (blast or beam) knocks it down
  (`downed`) for 1.5 s; it also drops to strike (during the windup) and climbs back slowly
  afterwards, which is the punish window. Lift works like the player's flight: display origin
  and body offset move together.
- Bosses: the first time each boss is seen, the Lens opens as a "¡NUEVO RIVAL!" card (flag
  `bossCard.<id>`, waits for dialogue to close). Boss pattern `ultimate` (`EnemyAi.ultimate`):
  a long telegraphed windup (toast + rising screen shake + gathering sparks) and then several
  staggered radial waves of big shots; Sarn uses it once per pattern cycle in the crystal form.
- Stat points per level: 3 (reference FAQ), was 2.
- Powers match who the character is (user request): `CharacterDef.canFly` — Tavi (ki user)
  flies; Okun (stone) can't ("las piedras no vuelan"): Shift explains it, and on the continent map
  the first party member who can fly is drawn carrying the party. Okun has no ki beams or orbs:
  his techniques have `look: 'rock'` (tumbling stones, no glow) and count as `thrown`, so ki
  drinkers can't absorb them; Veta de Magma was removed (save v5 drops removed techniques).
  Enemies too: harpooners and Grell throw harpoons (Grell lost his ki ring), prospectors and
  Okun's rival form throw rocks, mist runners throw darts, Sarn fires crystal shards
  (`ProjectileParams.look`). Only ki and shards glow.
- Scenery proportions (user request, measured on the reference footage: trees ~3-4 characters
  tall, loose boulders ~2/3 of one, rock masses with a visible face, heavies ~1.5x a person):
  `scenes/world/Scenery.ts` stands full-size sprites (`ui/sceneryTextures.ts`, procedural) on
  `tree` and `boulder` collision tiles and hides the tile art; the tile stays the collider (trunk
  or base). Trees are 50-60x72-84 px, depth-sorted with actors, and fade to half alpha when the
  player is behind the canopy. Rock and canyon walls show a cliff face on their south edge (two
  tiles when thick enough) with a cast shadow; their tops are low-contrast rough stone (the one
  tile repeats). Golems (`large` class) are drawn at 2x (48x42 frame) so they tower over people.
- Shot sprites are drawn `lift` px straight above their ground point at any rotation: the
  display origin offset is counter-rotated (it used to turn with the sprite, so shots fired left
  were drawn under the feet and vertical ones off to the side).
- Equipment (save v4): four slots — head, body, hands, feet — shared by the whole party, one item
  each. Every piece has `minLevel`: the _active_ character must have reached it to put it on
  (taking off is always allowed; a lower-level member switching in keeps the effects). Items
  below the level show grey in the Items tab. Current pieces: Cinta de cobre (head, 8), Abrigo
  de guardián (body, 1), Brazal de cantera (hands, 6), Lastre de entrenamiento (feet, 3).
- Chapter title cards (`title` cutscene step) open each chapter: 1 Temblor en la Atalaya
  (opening), 2 La Hondonada de Cobre (`cobreArrive`), 3 La Mano de Cristal (`sarnArrive`).
- Ki blasts fly until they leave the screen (GBA style; user reported they died mid-screen):
  techniques have no lifetime, only an optional `range` for close moves (Okun's ring).
  `shotReach` in `systems/combat.ts`; projectiles with `untilOffscreen` vanish past the view.
- Readability (user: "cuesta leer"): any text drawn over the map sits on a plate —
  `ui/TextPanel.ts` (dialogue-box palette, `PANEL_STYLE`) for toasts, barrier level plaques
  (white text framed in the character's color, drawn above actors), the special's name and the
  continent map labels; the HUD status block and the bottom strip have dark backings too. Toasts
  wrap to two lines, stay up `1.8 s + 55 ms/char` (max 6 s) and queue instead of cutting each
  other; the bottom HUD hides while a dialogue box is open. Never tint text with the color of
  what it sits on.
- Cutscenes (phase 20, for GBA-style in-engine scenes): scripts are data (`data/cutscenes.ts`,
  types and picking in `systems/cutscene.ts`), run by `scenes/world/CutsceneDirector.ts` with
  promises: walk (tweens; scripted actors ignore collisions), face/look, emotes, poses, camera
  pans, shake/flash, spawn/despawn actors, flags, sounds, `together` for parallel steps, and
  `talk` (dialogue boxes now show the speaker's portrait). Triggers: zone enter, Tiled `cutscene`
  area objects, approaching a boss, defeating a boss. Each plays once (`cs.<id>` flag). While
  one runs the world is cinematic: letterbox bars, HUD hidden, player and enemies hold still.
  `tests/cutscenes.test.ts` checks every reference (actors, dialogues, tiles, triggers).
- Boss intros/outros are cutscenes only (`boss` / `bossDefeated` triggers); there is no
  generic boss dialogue fallback anymore. Party members join through the cutscene `join` step,
  which sets their `joinFlag` and raises them to a story level with `raiseToLevel` (EXP-
  equivalent, so they arrive with stat points to spend).
- Hondonada de Cobre (phase 21): canyon tiles appended to the tileset (`canyon-floor` q,
  `canyon-wall` Q tall, `copper-ore` u). Flow: arrival → witness Okun in the camp → duel
  (`okunRival`, an enemy that reuses Okun's look) → Sarn shows up and flies off → Okun joins at
  level 10 → his first boulder is right there (objective step uses `gateBroken`).
- Arc 1 finale (phase 22): Sarn waits at the valley anchor (enemy objects can carry
  `requiresFlag`; his needs `okunIntroduced`). Bosses transform mid-fight GBA-style: a
  `BossPhase` with `look` (+ optional `nameKey`) swaps the sprite sheet
  (`SHEET_KEYS.enemy(id, phase)`, listed in the sprite catalog) and renames the boss bar; a
  cutscene with trigger `bossPhase` plays the reveal (its `transform` step swaps the look) and
  phases without one swap right away. Cutscene spawns of a party member who is the player right
  now alias to the player, so scripts spawn both heroes and it works with either one active.
  `title` steps show a full-screen card (chapter ends). The map changes with the story through
  Tiled `tileSwap` objects (`flag` + `gid`, applied live, e.g. the anchor snapping), and
  continent landmarks can be hidden until a `revealFlag` (Marismas de Sal, La Grieta: teasers
  for arc 2). `chestOpened` is a condition (objective "open the vault chest").
- `tests/content.test.ts` cross-checks maps ↔ data ↔ strings (every enemyId/npcId/itemId exists,
  the slice has its 3 collectibles/gate/boss, a field sweep reaches level 5).
- Audio: every sound goes through `services/audio.ts` hooks (`SfxId`). If a file is registered in
  `data/audio.ts` it plays; otherwise the synth in `audio/sfx.ts`. No audio files ship.
- Soundtrack (2026-11-01, user: "compone la música"): original chiptune written as text in
  `audio/tracks.ts` (bars = chord + melody tokens; bass/arp/drum styles from `audio/theory.ts`,
  compiled by `audio/song.ts`), played by `audio/music.ts` (lookahead WebAudio scheduler, GBA-like
  pulse/triangle/noise voices, per-track echo and low-pass, crossfades). Zones pick a track with
  `ZoneDef.music`; boss aggro switches to `boss` (`finale` for Vesk Final, El Fondo and the Echo);
  a boss defeat plays the `victory` stinger and returns to the zone track; game over stings
  `gameOver`; the epilogue uses a cutscene `music` step and `credits` plays its own track. Music
  has its own volume (`Options.music`) on a bus at 0.55 under the effects; a limiter on master;
  the context suspends while the page is hidden. Dev builds expose `window.__audio`. A cutscene
  that changed the music hands back to the zone's track (or `boss`) when it ends.
- Final boss balance (2026-11-01): measured as seconds of landed melee at the boss's level
  (chapter bosses 20-35 s). Vesk Final 2700 HP (36 s); El Fondo 3900 HP (48 s, mostly at range
  in phases 1-2; the colossus phase is the last 40%); Eco del Fondo 5800 HP (61 s, optional).
- Hit-stop pauses Arcade physics and resumes with `window.setTimeout` (real time), because scene
  timers would also be affected by the pause.
- Options (volume, show controls hint) persist separately from the save (`anclas.options`),
  so they survive "new game".
- Runtime bundle is Phaser only (~390 kB gzip); no chunk splitting needed for a local game.
- Phase 7 replaced the placeholder prototype cast with the original one (Tavi, Okun, Iolé, Pim,
  Nilo, Grell, Sarn). Prototype saves (before v2) are no longer loaded; keep
  zone ids (`hub`, `field`) and Tiled object names stable so persistent ids don't change.
- The enemy scanner is the Watchtower **Lens** (`LensScene`, action `lens`).
- Flight (phase 8): `Player.flying` + a visual `altitude`. The sprite is lifted by raising the
  display origin and the body offset together, so the physics body (feet) never moves. The tile
  collider has a process callback: while flying only `blocksFlight` tiles collide. Shots skip
  `low` tiles (water, bushes). Keep tall tiles around gated areas (see Barriers).
- Flying disables melee/block, ki regen and interactions (to avoid sniping from over water).

- Visual pass (phase 9): sprites and tiles share one finish — flat-color paint, then
  `finishGrid` (top-left light, colored outline, 15-bit snap). 14 poses per facing; Actor plays
  `<sheet>-idle|walk|fly-<facing>` loops. The transformation is shown with glow lines, eyes and a
  light scarf plus a soft halo with rising motes (deliberately not a hair-color/flame-aura look).
- Tile names were re-themed (wood/stone Watchtower, meadow, cloud sea, cliff, anchor); gids are
  unchanged because order is preserved. Object tiles are transparent; build-maps fills the ground
  under them from the most common walkable neighbor.
- Sprite pipeline (phase 13, spec in `docs/SPRITES.md`, constants in `ui/spriteSpec.ts`):
  frames are 24×32 (`humanoid`) or 32×32 (`large`), chosen by the user for GBA-like detail.
  Generated humanoids (redrawn after the user compared them with GBA footage: "se le ven bien
  las extremidades"): bodies are painted at native 24×32 from a per-pose skeleton (shoulder/
  elbow/hand, hip/knee/ankle; `sideRig`/`frontRig` in `ui/humanoid.ts`), limbs as thick lines,
  and a limb in front of the body gets a dark contour (`stamp`). Heads keep the 16×24 hair/face
  shapes enlarged ×4/3. Golems are still painted small and enlarged. Swing poses outlast the
  active window by 80 ms and freeze through the hit-stop. Bodies are feet boxes (`FEET_BOX`) placed
  from the frame size, so any sheet size works. `sprites:check` writes a manifest of valid sheets
  that Preload loads; `predev`/`prebuild` run it with `--no-fail`. `ui/spriteSpec.ts`,
  `ui/humanoid.ts`, `ui/actorFrames.ts` and `data/enemies.ts` use explicit `.ts` imports
  because the asset scripts load them with plain Node.
- Combat feel (phase 14, after the user reported missed ki shots and stiff turning):
  `systems/playerCombat.ts` is a pure, tested state machine (free/swing/cast/block/hurt/downed)
  that Player steps every frame. Presses are buffered (`inputBufferMs`); a swing is committed only
  through startup+active, then movement, guard or ki cancel the recovery; a 4-hit chain whose last
  hit launches. Every swing/shot re-reads the 8-way input; swings bend toward the best enemy in a
  small cone (`systems/aim.ts`, soft lock), specials go exactly where aimed (user feedback); the
  sprite shows the closest 4-way facing.
- Projectiles live in **ground space**: the body circle is at feet level (like actors) and the orb
  is drawn `lift` px higher (display origin + body offset, same trick as flight). Before, shots
  flew 8 px above the feet and passed over targets standing on the same row.
- Text legibility: the `pxs` font has a baked 1px black outline (8 neighbors) and 2px letter
  spacing; keep its tints light (dark tint on a black outline is unreadable). HUD hints sit on a
  dark strip.
- Special selector (phase 15, user request): `systems/specials.ts` lists the active character's
  techniques then transformations; Q/LB cycles, the ki button (S/B) runs the selection. The HUD
  strip (`ui/SpecialSelector.ts`) sits under the portrait. The W/Y transform shortcut was removed
  at the user's request: transforming is only done from the selector.
- Run (phase 15): double-tap a direction (`systems/run.ts`): short burst, then ×1.55 while any
  direction is held. Works in the air too.
- Punches keep contact (user feedback): the hitbox (`Player.meleeHitbox`) is a strip from the
  body out to `reach` (where the fist is drawn), so a blow only lands when the fist visibly
  touches; plain hits push little and every swing steps in about as far (`melee.lungeSpeed`),
  so a string stays glued to the target. Soft lock only within touching distance.
- Melee style per character (phase 17): `CharacterDef.melee` (`MeleeStyle`) overrides the default
  4-hit chain in `BALANCE.melee`. Okun: 3 slow hits, more power and reach, takes less stagger and
  knockback (`stagger`). Damage per swing is `comboMults[step] × power`.
- Continent map (phases 10-11): `WorldMapScene` replaces the flight-circle menu. World stops the
  HUD scene and starts the map; landing starts World with the zone's `flightSpawn` (World
  relaunches the HUD). Terrain is generated by `systems/terrain.ts` (seeded value noise, drawn at
  2x for a reduced-map look); landmarks are data (`data/worldMap.ts`). The user asked for a
  grounded world, not sky islands: keep the setting on land.
- Perspective continent map (phase 16, user request for a 3D-feeling flight like the GBA
  games): `WorldMapScene` draws the ground "Mode 7" style on the CPU (`scenes/worldmap/
  Mode7Ground.ts`, ≤480×270 px per frame, 60 fps) with the projection in `systems/mode7.ts`. The
  camera looks north from behind the flyer; arrows keep the old map-direction controls (the
  user asked to keep them). Fog uses precomputed levels plus 2×2 ordered dithering instead of
  per-pixel blending. Landmarks and clouds are billboards; landing rings are stamped into the
  ground colors; slope shading comes from `terrainHeight`. A top-down minimap stays in the corner.
- Map altitude (user request, like the GBA flight): hold attack (D/A) to climb, ki (S/B) to
  descend; reaching the ground inside an unlocked ring lands there (`stepAltitude`), elsewhere the
  flyer stops at a low hover. There's no "go back" key anymore. `flightCamera` raises and pulls
  the camera back with altitude so the land shrinks; the flyer is drawn a fixed lift above its
  shadow rather than truly projected (a true projection floats it up into the sky).
- Boss power-up (reference duel, ~2.75 s): crossing a phase threshold no longer transforms the
  boss instantly. `WorldScene.onBossPhaseChange` (after the phase cutscene, if any) calls
  `Enemy.startPowerUp`: the boss stands rooted in a flame aura (`drawAura`), with super armor but
  taking ×1.3 damage (`POWER_UP_DAMAGE_MULT`), so it is a window to punish. A phase with a new look
  takes 2.6 s, a plain rage 1.5 s. On release `transformBoss` + `bossBurst` (flash, shockwave
  that hits a player within 44 px) and the phase's `dialogueId`. Cutscenes only set up the moment
  (`sarnTransform` no longer does the transform itself).
- Heavies (reference: big humanoids ~1.5x a character that barely flinch): look kind `brute`
  draws the humanoid art upscaled 3/2 into the `heavy` sprite class (36×48 frame, 16×9 feet box,
  own shadow). `campBruiser` (field camp) and `quarryBrute` (cobre camp): slow, high HP,
  knockbackResist 0.85-0.9, melee strings of 2-3 blows.
- Arena pillars (reference boss arenas): tiles `pillar` (`P`) and `canyon-pillar` (`K`), solid,
  block flight and shots (not `low`). Scenery stands a ~44-52 px rock column on them that fades
  like a canopy. Four in the field crater (Grell/Sarn) and four in Okun's ring.
- Money (save v6): anchor shards (`GameState.money`). Every defeated enemy scatters them
  (`systems/economy.ts`: `moneyDrop` from level and EXP, ×4 for bosses; `splitMoney` into up to
  6 pickups that vanish after 15 s). HUD counter top-right. Shop: an NPC with `NpcDef.shop`
  opens a choice-menu loop after its dialogue (list → description + buy/no → list); only items
  with `price` are sold. Oda the peddler in the Watchtower corridor.
- SPD (save v6): fourth stat. +1% move speed per point (max ×1.6) and −0.5% melee recovery per
  point (min ×0.7). Points per level 3 → 4; the migration gives old saves SPD 1 plus one free
  point per level already gained.
- Item get: chests and NPC gifts play `Player.showOff` (faces the camera, arms up using the

## Story bible

The user loves the GBA action-RPG structure (several playable characters, chapters that switch
between them, lots of missions, barriers you come back to later, collectibles, post-game). Mirror
those mechanics; keep every name, character, place and line original. Creative freedom was given:
only ask the user about things that need their attention.

- World: the continent of Aurel (on land, not in the sky). Each region is kept stable by an
  **anchor**, an ancient crystal buried in it; pulling one out makes the land quake and sink. The
  **Atalaya** (Watchtower) is a guild of wardens who can truly fly, based in a coastal tower.
- Playable cast (each with a combat style, specials and field ability used by barriers):
  - **Tavi Ondra** (lead, courier, teal hair, long red scarf): balanced, ki volleys; form
    _Despertar del Ancla_. Breaks her own colored barriers.
  - **Okun** (stone-skinned, southern canyons): slow heavy chain, rock techniques; his melee
    smashes **boulders** (`kind: 'boulder'` gates). Joins in arc 1.
  - **Capitana Iolé** (mentor, mechanical wing): playable chapter in arc 2 while Tavi is missing;
    gust attacks; her field ability opens wind vents (future barrier kind).
  - **Nilo** (nervous junior warden → brave): small and quick; joins in arc 3; slips through
    crawlspaces (future barrier kind).
- Villains: **Sarn, la Mano Gris** (scavenger boss selling anchor crystals), **Grell** (harpoon
  lieutenant), **Vesk** (Mano Gris alchemist who grafts anchor light into golems, arc 2), and
  **El Fondo** (something deep under the land feeding on anchor light).
- Arc 1 "El Ancla Rota" (done, flag `arc1Done`): quake → Valle Bruma (Grell) → Hondonada de
  Cobre (duel then alliance with Okun) → Sarn rips the valley's crystal, fuses it into his hand
  ("Sarn, Mano de Cristal") → when he falls the light sinks underground, the anchor snaps and
  something breathes below; Sarn escapes → Iolé opens the Atalaya vault (`vaultOpened`) and the
  map reveals the salt marshes and La Grieta (`anchorBroken`).
- Arc 2 "Tierras que se Hunden": regions start sinking; evacuation missions (escort/rescue), Tavi
  and Okun split (alternating chapters), Iolé defends the Atalaya, Vesk's golem works in the salt
  marshes, Tavi is taken below and comes back changed (second form).
- Arc 3 "El Fondo": descent under the continent with the whole party; Nilo's courage; final
  battle; epilogue with Iolé ("no hay vuelta atrás") and post-game in the deep zone.
- Barriers are planted early and opened later: colored level barriers per character, Okun's
  boulders, and story seals (`kind: 'seal'`, open on a flag) in already-visited zones.
